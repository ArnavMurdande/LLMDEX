Methodology

LLMDEX is designed as a financial-grade analytics index. Every ranking decision is documented, every data point is traceable, and no value is ever fabricated. Below is how the system works.

Data Sources

Artificial Analysis is the single source of truth. The scraper activates its expanded table, captures every current model and visible field, and health-checks every snapshot before publication.

Performance Leaderboard

The Artificial Analysis Intelligence Index is used unchanged. Expanded-field completeness is displayed separately and never demotes a new model. Cost and speed do not affect this ranking.

Value Leaderboard

Composite: 50% Performance + 30% Cost Efficiency + 20% Speed. Missing components redistribute weight proportionally. Uses adjusted performance for fairness.

Efficiency Leaderboard

Efficiency = Performance / Blended Cost, normalized as percentile ranks to prevent chart distortion. Only models with adjusted performance ≥ 25 qualify. Free models receive maximum efficiency.

Coverage Transparency

Completeness covers four groups: headline index, detailed benchmarks, pricing, and runtime. It is transparent metadata only; it does not override the Artificial Analysis performance order.

Limitations

No single metric captures "intelligence." Benchmarks test narrow capabilities and Artificial Analysis can revise its methodology or data. Costs change frequently. Use LLMDEX as one input to your evaluation, not the only one.
